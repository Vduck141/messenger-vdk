**Mới trong 0.6.6 – gói chẩn đoán để báo lỗi**
- **Tạo gói chẩn đoán**: menu **Trợ giúp → Tạo gói chẩn đoán…** (hoặc Cài đặt (⌘,) → Chung → *Chẩn đoán*). App lưu 1 file `.zip`, bạn gửi file đó cho người hỗ trợ (qua Messenger, Zalo…). App không tự gửi đi đâu.
- **Nhật ký đăng nhập rõ hơn**: lúc chưa vào màn chat (trang đăng nhập, trang kiểm tra bảo mật), app ghi trang đi qua đâu, server trả gì, khung kiểm tra bảo mật có tải được không, link nào bị mở ra trình duyệt. Vào chat rồi thì chỉ ghi lỗi quan trọng.
- Trong gói **không có** mật khẩu, email, số điện thoại, giá trị cookie hay nội dung tin nhắn. Phần sau dấu «?» của link bị bỏ, tên trang cá nhân được che.

**Không đăng nhập được (bấm Đăng nhập xong bị quay lại trang đầu)?**
1. Cập nhật lên 0.6.6 (cách bên dưới).
2. Thử đăng nhập lại 1 lần đến khi bị quay lại.
3. **Trợ giúp → Tạo gói chẩn đoán…** → lưu → gửi file zip cho người hỗ trợ.

**Đang dùng 0.6.1 – 0.6.3?** Cài đặt (⌘,) → Chung → *Kiểm tra cập nhật* → *Cập nhật ngay*. Không cần đăng nhập Messenger để cập nhật. Đăng nhập, cài đặt giữ nguyên.
**Đang dùng 0.6.0?** Tải DMG bên dưới, kéo đè vào Applications 1 lần.

## Cài lần đầu
1. Tải **Messenger.Vdk.0.6.6.dmg** → bấm đúp → kéo **Messenger Vdk** vào **Applications**.
2. Mở lần đầu: macOS chặn vì app chưa được Apple công chứng → bấm **Xong**.
3. **Cài đặt hệ thống → Quyền riêng tư & Bảo mật** → mục **Bảo mật** → «"Messenger Vdk" đã bị chặn…» → **Vẫn mở** → nhập mật khẩu máy.
4. Mở lại app.

Yêu cầu: macOS 14+, chip Apple. Hướng dẫn chi tiết (có ảnh): https://github.com/Vduck141/messenger-vdk/blob/main/HUONG-DAN-CAI.md

File `.zip.sig` là chữ ký số để app kiểm bản cập nhật – không cần tải.
